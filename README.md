# my-weird-php-game
A weird little terminal game written in PHP that accidentally turned into a tiny roguelike engine. <br />
This project was written during spare time throughout an internship using <a href="https://onecompiler.com/">OneCompiler</a>, <br />
so the code quality is questionable and bugs are guaranteed.

## controls
- w: move up
- a: move left
- s: move down
- d: move right

## run


```bash
php -f v1.1.php
```

### optional map size
```bash
php -f v1.1.php 20 10
```

## requirements
- php >= 8.3
